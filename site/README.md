# Ford Focus ST MK3

Static, responsive single-page site. Serve the `dist` directory to preview.

## Replace placeholders

Put the real vehicle photos in `dist/assets/`. Set the five paths at the top of `dist/app.js`: `hero`, `front`, `rear`, `interior`, `detail`. Example: `front: 'assets/front.jpg'`. The hero uses a dark overlay for text contrast; the vehicle image itself is unchanged. All gallery images open in the keyboard- and touch-enabled fullscreen viewer.

The WhatsApp number and message are configurable in `dist/app.js`. Current number: +41 78 260 38 99.
